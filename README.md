# Notification System Assignment

This repository contains the solution for the Frontend Track Assignment, including a Notification System backend, frontend, and a logging middleware.

## Project Structure

*   `logging_middleware`: A reusable Express middleware for logging requests and errors.
*   `notification_app_be`: An Express backend exposing an API for the notification system.
*   `notification_app_fe`: A React/Vite frontend for the user interface.
*   `notification_system_design.md`: The architecture design document for the notification system.

## Setup Instructions

Please navigate to the respective directories (`notification_app_be` and `notification_app_fe`) and run `npm install` followed by their respective start commands.
